# Web Technologies Assignment 01 - Digital CV

A structural, web-based Curriculum Vitae developed as the first assignment for the Web Technologies course in the BS Information Technology program at PUCIT. This project focuses strictly on core document structure and layout fundamentals.

##  Tech Stack
*   **HTML5:** Used for the semantic structure, text formatting, and defining the layout skeleton of the CV.
*   **CSS:** Applied at a fundamental level (focusing primarily on margins, padding, and basic spacing) to organize the resume content cleanly without relying on complex stylesheets, flexbox/grid layouts, or external frameworks.
